# 꾸꾸(KKUKKU) 약관 및 안내

시행일 2026-11-20. 앱의 동의 화면과 내 정보 > 약관 메뉴에 표시되는 문구와 같습니다(src/legal/terms.ts).

## 이용약관 (필수 동의)

무료 앱이며, 추천과 자동 입력은 참고용이에요.

### 서비스

꾸꾸(KKUKKU)는 옷장에 등록한 옷과 오늘의 날씨로 코디를 추천하는 무료 앱입니다. 계정이 없습니다. 운영자의 서버는 날씨 예보를 미리 받아 전달하는 데만 쓰며, 옷 사진과 옷 정보는 서버로 보내지 않습니다.

코디 추천과 사진 분석에 따른 자동 입력(배경 제거, 카테고리·색상·계절 제안)은 참고용입니다. 정확성을 보장하지 않으며, 옷 정보는 사용자가 확인하고 고른 값으로 저장됩니다.

카테고리 제안에 쓰는 옷 분석 모델(약 48MB)은 처음 실행할 때 한 번 내려받습니다. 받지 않아도 앱을 쓸 수 있으며, 이때는 카테고리를 직접 고릅니다.

날씨 정보는 Open-Meteo 가 제공하며 실제 날씨와 다를 수 있습니다.

### 이용 조건

만 14세 미만은 보호자의 동의를 받은 뒤 이용해 주세요.

앱은 GitHub 의 꾸꾸 저장소(github.com/chyj-dv/kkukku)에서 배포합니다. 다른 곳에서 받은 설치 파일은 바뀌었을 수 있으니 설치하지 마세요.

### 사용자가 지킬 것

자신이 권리를 가진 사진만 등록합니다. 다른 사람의 얼굴이나 개인정보가 찍힌 사진은 등록하지 않습니다.

### 서비스의 변경과 중단

무료로 제공하는 서비스라 기능이 바뀌거나 중단될 수 있습니다. 날씨 서버나 모델 내려받기가 멈추면 그 기능은 쓸 수 없지만, 기기에 저장한 옷장과 코디는 그대로 남습니다.

운영자는 고의나 중대한 과실이 없는 한 추천, 자동 입력, 날씨 정보가 틀리거나 서비스가 멈춰 생긴 손해에 책임을 지지 않습니다.

### 데이터와 변경

모든 데이터는 이 기기에만 저장되며 백업되지 않습니다. 앱을 삭제하거나 기기를 바꾸면 데이터가 사라지고 복구할 수 없습니다.

약관이 바뀌면 앱을 열 때 바뀐 내용을 보여 드리고 다시 동의를 받습니다.

### 문의

문의는 꾸꾸 저장소의 Issues(https://github.com/chyj-dv/kkukku/issues)로 해 주세요. GitHub 계정이 필요합니다.

## 개인정보 처리 안내 (필수 동의)

사진과 옷 정보는 기기에만 저장되고, 날씨 조회에만 대략적인 위치를 보내요.

### 기기 안에서만 처리하는 정보

옷 사진, 옷 정보(이름, 카테고리, 색상, 스타일, 계절, 브랜드), 선호 스타일, 저장한 코디는 이 기기 안에만 저장되며 운영자나 다른 곳으로 보내지 않습니다.

사진 분석(배경 제거, 카테고리·색상 제안)은 기기 안의 모델로 처리하며 사진을 외부로 보내지 않습니다.

앱 안 카메라로 찍은 사진은 기기의 사진 앨범에 저장하지 않고, 옷을 등록할 때 앱 안에만 저장합니다.

옷을 등록하면 사진을 긴 변 1600픽셀 이하로 줄여 앱 안에 저장합니다. 앨범이나 파일에서 고른 원본은 바꾸지 않습니다.

추천 코디를 이미지로 저장하면(선택) 그 이미지를 기기의 사진 앨범(꾸꾸)에 저장합니다. 이 이미지도 외부로 보내지 않습니다.

### 외부로 보내는 정보

앱은 아래 세 곳과만 통신합니다. 이름, 연락처, 계정처럼 이용자를 알아볼 수 있는 정보는 보내지 않습니다.

날씨 서버(운영자, Cloudflare Workers): 날씨를 볼 때와 앱을 열 때 대략적인 지역(위도·경도를 0.1도, 약 10km 단위로 반올림한 지역 번호)을 보내 그 지역의 예보를 받습니다. 서버는 지역별 예보와 각 지역을 마지막으로 조회한 시각만 저장하며(최대 7일), 이용자를 식별하는 정보와 IP 주소는 저장하지 않습니다.

Open-Meteo(open-meteo.com): 날씨 서버에 연결되지 않을 때만, 같은 지역의 중심 좌표로 예보를 직접 조회합니다.

GitHub(github.com): 옷 분석 모델 파일(약 48MB)을 처음 실행할 때나 옷 추가 화면에서 받기를 누를 때 한 번 요청합니다. 모델 파일만 요청하며 사진이나 옷 정보는 보내지 않습니다.

위치 권한을 허용하지 않으면 위치를 보내지 않고 서울의 날씨로 추천합니다.

조회한 날씨와 반올림한 좌표는 다음 조회까지 기기 안에 임시로 저장합니다.

### 국외로 전달되는 정보

위 통신 과정에서 기기의 IP 주소와 접속 기록이 각 업체의 서버에 전달됩니다. 서버는 국외에 있을 수 있으며, 처리와 보관은 각 업체의 개인정보 처리방침을 따릅니다.

받는 곳(나라)과 목적: Cloudflare, Inc.(미국 등 여러 나라의 서버) — 날씨 서버 운영. Open-Meteo(스위스 등) — 예보 제공. GitHub, Inc.(미국, 운영사 Microsoft) — 모델 파일 전달. 전달되는 때는 각 통신이 일어날 때입니다.

원하지 않으면 기기의 인터넷 연결을 끈 상태로 쓰세요. 이때도 저장한 옷장과 코디는 쓸 수 있고, 날씨는 마지막으로 받은 예보로 추천합니다. 모델을 받지 않으면 GitHub 와는 통신하지 않습니다.

### 이용자의 권리

등록한 옷과 저장한 코디는 앱에서 언제든 보고 고치고 지울 수 있습니다. 앱을 지우면 기기 안의 모든 데이터가 지워집니다.

운영자는 이용자의 옷 사진, 옷 정보, 위치를 갖고 있지 않습니다. 그래서 운영자에게 열람이나 삭제를 요청할 데이터가 없습니다.

만 14세 미만 아동도 같은 방식으로 처리하며, 운영자는 아동의 개인정보를 따로 수집하지 않습니다. 보호자의 동의를 받은 뒤 이용해 주세요.

### 안전을 위한 조치

사진과 옷 정보는 기기 밖으로 보내지 않습니다. 앱 데이터는 기기의 자동 백업에서 빼서 클라우드에 올라가지 않습니다.

앱 잠금(선택)을 켜면 직접 만든 패턴을 그대로 저장하지 않고, 임의의 값을 섞어 되돌릴 수 없게 변환한 값만 기기의 보안 저장소에 보관합니다. 패턴은 외부로 보내지 않습니다.

모델 파일은 받은 뒤 크기와 체크섬이 맞을 때만 씁니다.

### 보관과 삭제

옷을 삭제하면 그 옷의 사진과 정보가 함께 삭제됩니다. 앱을 삭제하면 기기 안의 모든 데이터가 삭제됩니다.

앱 잠금 패턴을 잊으면 되찾을 방법이 없습니다. 잠금을 풀려면 기기 설정에서 앱 데이터를 지워야 하며, 이때 등록한 옷과 저장한 코디도 함께 삭제됩니다.

### 문의와 변경

문의는 꾸꾸 저장소의 Issues(https://github.com/chyj-dv/kkukku/issues)로 해 주세요. GitHub 계정이 필요합니다.

이 안내가 바뀌면 앱을 열 때 바뀐 내용을 보여 드리고 다시 동의를 받습니다.

## 접근 권한 안내 (안내)

카메라·사진·위치 권한은 모두 선택이며, 기능을 쓸 때 물어봐요. 앱 잠금도 선택이에요.

### 선택 권한

카메라: 앱 안 카메라로 옷을 촬영해 등록할 때 사용합니다. 찍은 사진은 앨범에 저장하지 않으며, 마이크는 사용하지 않습니다.

사진(앨범): 앱 안 갤러리에서 앨범별 사진을 보여 주고 옷 사진을 골라 등록할 때 사용합니다. 사진은 기기 밖으로 보내지 않으며, 고른 사진만 앱 안에 줄여 저장합니다. 추천 코디를 이미지로 저장할 때는 사진 앨범에 쓰기만 하며, 이 경우에만 저장 권한을 물어봅니다.

위치(대략적인 위치): 현재 지역의 날씨로 추천할 때 사용합니다. 정확한 위치 권한은 요청하지 않습니다.

### 따로 묻지 않는 기본 권한

인터넷과 네트워크 상태: 날씨를 받고 옷 분석 모델을 내려받을 때 씁니다. 모델을 받기 전에 Wi-Fi 인지 모바일 데이터인지 확인해 크기를 알려 드립니다.

진동, 화면 켜짐 유지 같은 일부 기본 권한은 앱에 들어간 라이브러리가 선언한 것으로, 꾸꾸는 이 기능을 쓰지 않습니다.

지문·얼굴 인식, 다른 앱 위에 표시, 정확한 위치, 마이크 권한은 요청하지 않습니다.

### 앱 잠금과 화면 가리기(선택)

앱 잠금을 켜면 앱을 열 때와, 앱을 나갔다가 정한 시간(기본 3분)이 지나 돌아올 때 직접 만든 패턴을 그려야 합니다. 지문·얼굴 인식이나 휴대폰 잠금 비밀번호는 사용하지 않습니다.

패턴을 여러 번 틀리면 잠시 기다린 뒤 다시 그릴 수 있습니다.

최근 앱 화면에서 가리기를 켜면 최근 앱 목록에 앱 화면이 보이지 않고, 앱 안에서 스크린샷과 화면 녹화가 막힙니다.

### 거부하거나 바꾸려면

권한은 그 기능을 처음 쓸 때 물어보며, 허용하지 않아도 나머지 기능은 그대로 쓸 수 있습니다. 허용 여부는 기기의 설정 앱에서 언제든 바꿀 수 있습니다.

## 사진 촬영·분석 안내 (필수 동의)

화질, 조명, 배경에 따라 배경 제거와 자동 입력이 틀릴 수 있어요.

### 자동 입력은 추정입니다

배경 제거와 카테고리·색상·계절 제안은 기기 안의 모델이 사진만 보고 추정한 값이라 틀릴 수 있습니다. 저장하기 전에 확인하고, 다르면 직접 골라 주세요. 저장한 뒤에도 옷 정보에서 고칠 수 있습니다.

### 무엇으로 분석하나요

배경 제거와 색상 제안은 앱에 들어 있는 모델과 규칙으로 계산합니다. 계절은 고른 카테고리로 정합니다.

카테고리 제안은 처음 실행할 때 내려받는 옷 분석 모델로 계산합니다. 모델을 받지 않았으면 카테고리를 직접 고르며, 옷 추가 화면에서 언제든 받을 수 있습니다.

모든 분석은 기기 안에서 하며, 사진을 외부로 보내지 않습니다.

### 결과가 달라지는 경우

카메라 화질: 사진이 흐리거나 해상도가 낮으면 옷의 경계와 무늬를 찾기 어렵습니다.

조명(광원): 어둡거나 노란 실내등, 강한 그림자, 역광에서는 색이 실제와 다르게 나옵니다. 예를 들어 흰 옷이 회색으로, 검은 옷이 남색으로 제안될 수 있습니다.

배경: 옷과 비슷한 색의 배경이나 무늬가 있는 바닥에서는 배경이 덜 지워지거나 옷의 일부가 함께 지워질 수 있습니다.

함께 찍힌 물건: 옷걸이, 손, 다른 옷이 함께 찍히면 그것까지 옷으로 인식할 수 있습니다.

찍는 방식: 사람이 입은 모습, 옷걸이에 건 모습, 바닥에 펼친 모습에 따라 카테고리 제안이 달라질 수 있습니다.

### 잘 찍는 방법

밝은 곳에서 흔들리지 않게, 옷과 다른 색의 단색 배경 위에 옷을 펼쳐 화면 가운데 오도록 찍어 주세요.
