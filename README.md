# 꾸꾸 (KKUKKU)

> 휴대폰 안에서 동작하는, 날씨와 내 옷장 기반 코디 추천 앱

내 옷을 사진으로 등록해 두면 오늘 날씨와 선호 스타일에 맞는 코디를 추천합니다. 옷 사진과 취향 데이터는 기기 밖으로 나가지 않습니다.
배경 제거, 카테고리·색상·계절 제안은 휴대폰 안의 모델(Meta PE-Core-S16, U²-Net 경량판)이 처리합니다.

졸업작품으로 만든 서버 기반 앱(Flask, MySQL, 서버 측 CLIP 추론)을 온디바이스 앱으로 다시 설계했습니다.
개발 단계 이름은 WearCast 였고, 패키지 이름(`com.wearcast.app`)은 기존 설치 데이터를 잇기 위해 그대로 둡니다.

이 저장소는 소개와 배포용입니다. 앱 설치 파일(APK)과 앱이 내려받는 모델 파일을 [Releases](../../releases)에 올립니다.
앱·서버·실험 코드는 공개하지 않습니다.

## 앱 내려받기 (Android)

APK 는 준비 중입니다. 올리면 [Releases](../../releases)에 버전, 크기, SHA-256 과 함께 올립니다.

### 설치 조건

* **Android 13 이상 권장.** 설치 자체는 Android 8.0(API 26) 이상에서 되지만, 기기 안 모델을 돌리는 ExecuTorch 가 Android 13 이상을 요구합니다.
  실기기 확인은 갤럭시 Note20(Android 13)에서 했습니다.
* **64비트 ARM(arm64-v8a) 휴대폰만** 지원합니다. 요즘 휴대폰은 대부분 해당합니다. x86 에뮬레이터에서는 설치되지 않습니다.
* **저장 공간 200MB 이상.** 설치 파일이 약 62MB 이고, 첫 실행 때 옷 분석 모델(48.4MB)을 내려받습니다. 등록한 옷 사진만큼 더 늘어납니다.
* iOS 설치 파일은 아직 없습니다.

### 설치 방법

**휴대폰에서 바로**

1. 휴대폰 브라우저에서 Releases 의 APK 를 내려받습니다.
2. 다운로드한 파일을 엽니다. "출처를 알 수 없는 앱" 설치를 물으면 그 브라우저(또는 내 파일 앱)에 **이 출처 허용**을 켭니다.
3. Play 프로텍트가 "확인되지 않은 앱"이라고 알리면 **세부정보 › 무시하고 설치**를 누릅니다(스토어를 거치지 않은 앱이라 나오는 안내입니다).

**PC 에서 USB 로**

```bash
# 휴대폰: 설정 › 휴대전화 정보 › 소프트웨어 정보 › 빌드번호 7번 눌러 개발자 옵션을 켜고, 개발자 옵션 › USB 디버깅을 켠다
adb install -r <내려받은 APK 파일>
```

내려받은 파일이 맞는지 확인하려면 Releases 에 적힌 SHA-256 과 비교합니다.

```bash
certutil -hashfile <APK 파일> SHA256   # Windows
shasum -a 256 <APK 파일>               # macOS / Linux
```

### 처음 실행하면

* 약관에 동의하고 선호 스타일을 고르면 **옷 분석 모델(48.4MB)을 한 번 내려받습니다.** Wi-Fi 면 바로 받고, 모바일 데이터면 크기를 알린 뒤
  누를 때 받습니다. 이 저장소의 Releases 에서 받으며, 사진이나 옷 정보는 보내지 않습니다.
  받지 않아도 앱은 쓸 수 있고(카테고리를 직접 고름), 옷 추가 화면에서 언제든 받을 수 있습니다.
* 카메라·사진 권한은 옷을 등록할 때, 대략적인 위치 권한은 날씨를 받을 때 묻습니다(거절하면 서울 날씨로 추천합니다).
* 날씨는 Open-Meteo 에서 받고, 답이 늦거나 실패하면 노르웨이 기상청(MET Norway)에서 받습니다. 약 10km 칸의 중심 좌표만 보내며,
  옷 사진과 옷장 정보는 보내지 않습니다. **운영자는 서버를 두지 않아 위치를 받지 않습니다.**
* 앱을 쓰지 않을 때도 가끔 마지막 지역의 예보를 받아 둡니다(내 정보 › 날씨 미리 받아 두기에서 끌 수 있음). 위치를 새로 확인하지는 않습니다.

## 구조

```
┌──────────────────── 휴대폰 ────────────────────┐
│ 옷 등록 → 배경 제거(u2netp) → 카테고리·색상·계절 제안(PE-Core-S16) │
│ SQLite(옷장, 임베딩, 코디, 사흘 치 예보) + 앱 폴더(옷 사진)          │
│ 추천: 날씨 필터 → 후보 → 점수 → 다양성 선택 → 코디 보드             │
└──────┬──────────────────────────────┬─────────┘
       │ 약 10km 칸의 중심 좌표만      │ 첫 실행 때 모델 파일 한 번
       ▼                               ▼
    Open-Meteo                     이 저장소의 Releases
       │ 2.5초 안에 답이 없거나 실패하면
       ▼
    MET Norway  →  둘 다 실패하면 기기에 저장한 예보로 지금 시각의 날씨를 계산
```
